Las Repollas del Abuelo

Website Planning Document

Site Name

Las Repollas del Abuelo

This name represents a family-oriented business that offers traditional, homemade-style products with a warm and friendly brand identity. The name evokes trust, heritage, and authenticity.

Optional domain: lasrepollasdelabuelo.com

Site Purpose

The purpose of this website is to serve as a simple e-commerce landing page. Customers can browse products, add items to a cart, submit reviews, and complete a basic checkout using JavaScript LocalStorage.

Scenarios

  • What products are currently available and in stock?
  • How much will my order cost before checkout?
  • Can I leave a review for a product I purchased?
  • Do you offer delivery or only pickup?

Color Schema

The following colors are used consistently throughout the website:

Primary – Used for headers, buttons, and highlights
Secondary – Used for headings and accents

Typography

Font Family: Poppins (Google Fonts)

  • Headings: Poppins, bold
  • Body text: Poppins, regular
